# API仕様

## 共通の返却形式

ツールの成功結果は`structuredContent`にJSONを返し、`content`にも同じJSONをテキストで格納します。全ツールの共通フィールドは`license`と`attribution`です。

ハンドラー内のエラーは`isError: true`、`structuredContent: { "error": "メッセージ" }`で返します。入力スキーマの検証はMCP SDKが行います。

## scp_search

SCP ENのitems・tales・hubs・goiを検索します。検索対象はタイトル、slug、タグ、シリーズ、ページ作成者です。本文は`scp_get_content`で取得してください。

| 入力                                | 型       | 内容                                                   |
| ----------------------------------- | -------- | ------------------------------------------------------ |
| `query`                             | string   | 検索語。省略時は全件から絞り込む                       |
| `site`                              | string   | `en`。省略時も`en`                                     |
| `tags`                              | string[] | すべて含むタグ。大文字・小文字を区別しない             |
| `series`                            | string   | シリーズの完全一致                                     |
| `created_at_from` / `created_at_to` | string   | 作成日時の下限・上限。境界を含む                       |
| `rating_min` / `rating_max`         | number   | ratingの下限・上限。境界を含む                         |
| `limit`                             | integer  | 既定20、最大50。1未満は1に補正                         |
| `sort`                              | string   | `relevance`、`rating`、`created_at`。既定は`relevance` |

すべて省略可能です。日付として解釈できない条件は無視し、作成日時が不明なページは日付条件で除外しません。

`results`の各要素に`link`、`title`、`url`、`page_id`、`rating`、`tags`、`series`、`created_at`、`creator`、`snippet`を返します。`series`と`creator`は省略される場合があります。`snippet`は検索用メタデータの抜粋です。

`relevance`は検索スコア降順、同点はrating降順です。`rating`と`created_at`も降順で並びます。

## scp_get_page

| 入力         | 型              | 内容                      |
| ------------ | --------------- | ------------------------- |
| `link`       | string          | ページslug。例は`scp-173` |
| `page_id`    | string / number | WikidotのページID         |
| `scp_number` | integer         | SCP番号                   |

いずれか1つが必要です。複数指定した場合は`link`、`page_id`、`scp_number`の順に使います。slugやページIDが複数のページに一致した場合はエラーを返します。SCP番号はitemsの正規キーを優先します。

`page`に、ページの識別情報・タイトル・URL・rating・タグ・作成者・参照先・画像などのメタデータを返します。

## scp_get_content

| 入力                | 型              | 内容                                         |
| ------------------- | --------------- | -------------------------------------------- |
| `link`              | string          | ページslug                                   |
| `page_id`           | string / number | ページID。`link`指定時は使わない             |
| `format`            | string          | 必須。`markdown`、`text`、`html`、`wikitext` |
| `include_tables`    | boolean         | `false`ならHTML由来の出力から表を除く        |
| `include_footnotes` | boolean         | `false`ならHTML由来の出力から脚注を除く      |
| `start_line`        | integer         | 1始まりの開始行。既定1                       |
| `max_lines`         | integer         | 返却行数。既定200、最大500                   |

`link`か`page_id`が必要です。本文の行数を超える開始行はエラーになります。`wikitext`は元のWikidotソースを返すため、表・脚注の除去は適用しません。

| 出力                 | 内容                                                |
| -------------------- | --------------------------------------------------- |
| `content` / `format` | 指定範囲の本文と形式                                |
| `images`             | 画像のURLとalt                                      |
| `source`             | 出典の`url`、`title`、`page_id`                     |
| `content_hash`       | 指定形式の全文に対する`sha256:`付きハッシュ         |
| `range`              | `start_line`、`end_line`、`total_lines`、`has_more` |

`content`配列には`scp://content/{link}`へのリソースリンクも返します。検索・本文取得の結果には`content_is_untrusted: true`、本文取得には`content_safety_notice`も含みます。

## scp_get_related

必須の`link: string`でページを指定します。`related`に関連ページの`link`、`title`、`url`、`relation_type`を返します。

referencesを先に、hubsを後に処理し、重複するリンクとデータに存在しないページを除きます。`relation_type`は`reference`か`hub`です。

## scp_get_attribution

必須の`link: string`でページを指定します。`authors`と`attribution_text`に作者一覧と帰属表示を返します。

標準の起動構成での作者の取得元はSCPPER APIです。取得に失敗した場合は作者一覧を空にし、帰属表示では`(unknown)`と記載します。取得済みのページURLとタイトルは維持します。

## リソースとプロンプト

| リソース               | 内容                                           |
| ---------------------- | ---------------------------------------------- |
| `scp://about`          | サーバーとライセンスの情報                     |
| `scp://page/{link}`    | `scp_get_page`と同じページ情報                 |
| `scp://content/{link}` | Markdown形式の本文取得結果。既定の行範囲を使用 |

リソースの本文は`contents[].text`にJSON文字列で返します。

| プロンプト                   | 入力                                                  | 用途                               |
| ---------------------------- | ----------------------------------------------------- | ---------------------------------- |
| `prompt_quote_with_citation` | `link`、`question`。ともに必須のstring                | 本文を取得し、出典付きで質問へ回答 |
| `prompt_rag_reader`          | 必須の`query: string`、任意の`limit: number`。既定`5` | ページを検索し、本文を取得して要約 |

両プロンプトは、出典URL・行範囲・本文ハッシュ・作者・ライセンスを回答に含める指示を生成します。

## 接続と設定

stdioとStreamable HTTPに対応します。起動方法と環境変数は[README](README.md)を参照してください。

HTTPでは`POST /mcp`で初期化し、以後は応答の`mcp-session-id`をヘッダーに指定します。`DELETE /mcp`でセッションを終了し、`GET /healthz`で稼働状態を確認できます。

ツールの呼び出し上限は、既定でセッションごとに60秒間で60回です。セッションIDがない場合はサーバー内で共通に数えます。リソース取得には、この制限と呼び出しログを適用しません。

呼び出しログには時刻、セッション、ツール名、引数と結果の要約またはエラーを記録します。引数の文字列は200文字、配列は50要素までに短縮します。

## データソースとライセンス

ページデータの取得元は[SCP Data API](https://scp-data.tedivm.com/)です。ETagとLast-Modifiedを使ってキャッシュを再検証し、同じURLへの同時リクエストはまとめます。本文は必要になった時点で取得します。

帰属情報にはページURL、タイトル、作者、CC BY-SA 3.0のライセンス情報を含めます。二次利用の条件は[SCP Wikiのライセンスガイド](https://scp-wiki.wikidot.com/licensing-guide)を参照してください。
